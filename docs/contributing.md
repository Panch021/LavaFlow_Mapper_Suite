# Contributing

Contributions of all kinds are welcome: bug reports, new volcano examples, documentation,
and code. The full guide is in
[`CONTRIBUTING.md`](https://github.com/Panch021/LavaFlow_Mapper_Suite/blob/main/CONTRIBUTING.md).

## Getting help

* **Questions and ideas**: GitHub Discussions or an issue labelled *question*.
* **Bugs**: open an issue with the *Bug report* template (include the OS, how you installed
  the suite, the volcano and period, and the error message).
* We aim to answer within **two weeks**. The project is maintained by researchers at
  IG-EPN alongside their monitoring duties.
